# ASK Arena — Block Rush
A mobile-first, offline-friendly browser game prototype inspired by the clean lobby and HUD conventions of mobile battle/runner games (not affiliated with Free Fire).

## Run it
- Extract the ZIP.
- Open `index.html` in a modern browser. For installable PWA behavior, serve this folder over HTTPS or localhost.

## Controls
- Mobile: tap left/right arrows, or swipe on the playfield.
- Desktop: arrow keys or A/D.
- Pause: top-right pause button or Escape/Space.

## Gameplay
Dodge incoming blocks by switching lanes. Every block passed safely gives 1 score and 1 coin. Collision eliminates the run. Coins and owned/equipped skins, username, and best score are stored locally in the browser.
